# STAGE-00A — Pilot decision (человек решает)

Полный источник шагов — `docs/ops/stages/STAGE-00A-PILOT.md`.
Шаблон решения — `docs/templates/PILOT_DECISION.md`.

## Твои границы

- Ты НЕ выбираешь пилот. Ты НЕ предлагаешь стек. Ты НЕ создаёшь ADR.
- Готовишь входные данные и черновик `PILOT_DECISION.md` с пустым решением.

## Что подготовить

1. По каждому из 15 открытых вопросов из `20_OPEN_QUESTIONS_AND_RESEARCH_BACKLOG.md`:
   варианты ответа, влияние на P0, на срок, на юридический риск, можно ли
   ответить экспериментом.
2. 2–3 правдоподобных пилота: ICP, профессия, workflow, страна, рынок,
   доступность данных, сложность, срок, цена привлечения, измеримый outcome,
   нужен ли LLM.

## Что делает человек

Заполняет `## Решение`, `## Пороги P0 gate`, `## Бюджет и срок`
и подписывает `signed_by` / `signed_at`.

## Контроль

```bash
python tools/runbook_validate.py --stage STAGE-00A
```

До подписи валидатор покажет `WAIT` по `human_signed` — это ожидаемо,
а не ошибка.

## Финиш

Передай человеку: какие вопросы дешевле решить сейчас, какие можно отложить,
где развилка с наибольшей ценой. Остановись.
