# ADR-0002 — BUSL для движка, MIT для остального — ОТКЛОНЁН

## Решение

Владелец отменил BUSL (2026-11-16). Репозиторий возвращается к единой MIT,
как до принятия этого ADR:

| Часть | Лицензия |
| --- | --- |
| `career-intelligence-research-specs-v02/` | MIT |
| `docs/` | MIT |
| `skills/`, `tools/`, `.github/`, `README*` | MIT |
| будущий `engine/` | MIT |

## Исходный контекст и почему отклонено

Темой ADR была двойная лицензия с защитой движка hosted/competing-ограничением.
Решение владельца: BUSL не используется. Архитектура остаётся примером
невозможного для двигателя открытого конвейера: спецификации, валидатор,
скиллы и движок — под MIT, без дополнительных ограничений.

Что остаётся верным:

- MIT-лицензия применяется ко всему репозиторию, включая гипотетический
  будущий `engine/`.
- Никакие тексты BUSL не публикуются; `LICENSES/` и `LICENSE-MAP.md` удалены.
- DCO-требование снято с CONTRIBUTING и PR-шаблона.

## Последствия

- Конкурирующие hosted-сервисы легальны по MIT. Это осознанный компромисс
  владельца ради открытости и минимального юридического шума.
- Монетизация (`MONETIZATION_STRATEGY.md`) не может строиться на ограничении
  лицензии; она строится на данных, outcome-verification и поддержке.
- Если после P0 gate владелец захочет вернуться к лицензионной защите —
  новое решение с новой нумерацией ADR.
