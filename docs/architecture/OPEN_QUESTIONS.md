# OPEN_QUESTIONS — реестр неопределённостей

Единый реестр вопросов, которые могут изменить архитектуру, контракты или
продукт. Формат полей — из `43_RESEARCH_BACKLOG_MASTER.md`:
вопрос, гипотеза, на что влияет, какие доказательства нужны, качество
источника, владелец, срок, порог решения, статус.

Правило архива: **не строить дорогую инфраструктуру под нерешённый вопрос,
который можно проверить вручную.**

Статусы: `OPEN` · `BLOCKED_ON_PILOT` · `DEFERRED` · `ANSWERED`.

## Как обновлять

1. Вопрос, влияющий на контракт, не закрывается в коде — только записью здесь
   и, при необходимости, ADR.
2. `ANSWERED` требует ссылки на решение: ADR, gate-отчёт или `PILOT_DECISION.md`.
3. Вопрос без владельца — это не вопрос, а шум. У каждой строки есть владелец.
4. Ответы не удаляются: строка остаётся с решением, чтобы не обсуждать то же
   самое через месяц.
