# contracts — замороженные контракты

Контракты заморавливаются в `STAGE-02` и утверждаются через ADR. Код пишется
только по утверждённым контрактам.

## Слои

| Путь | Слой |
| --- | --- |
| `events/EVENT-CATALOG.md` | 17 канонических событий, envelope, payload, privacy_class |
| `domain/DATA-MODEL-P0.md` | схема данных P0, DDL-проект |
| `api/API-FOUNDATION.md` | auth, tenant isolation, ошибки, пагинация, версионирование |

## Правила

- Любое изменение контракта — новая версия + ADR.
- Версионируется сам контракт, а не только код.
- Контракт без владельца и версии не считается замороженным.
- Тесты на соответствие контракту обязательны (conformance tests).
- Пока контракт не утверждён — код, который от него зависит, не пишется.
