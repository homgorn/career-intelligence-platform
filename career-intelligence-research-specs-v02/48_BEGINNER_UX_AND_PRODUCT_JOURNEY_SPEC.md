# Beginner UX & Product Journey Specification

## Main product journey
Discover work → identify one task → explain AI opportunity → select support mode → learn or delegate setup → test → verify → repeat → measure → expand.

## Interface modes
- Simple mode: task language, guided defaults, minimal settings.
- Advanced mode: tool comparison, workflow editor, integrations, cost and governance.
- Expert mode: APIs, agent configuration, evaluation, permissions and logs.

Users can switch modes; do not lock them into a beginner identity.

## Recommendation presentation
Show: "what you'll achieve", "what you need", "how long it may take", "what it costs", "what can go wrong", "how to check", "do it yourself / guide me / do it for me".

## Empty states
Offer a concrete starter task based on profession and context. Do not show an empty tool marketplace.

## Progress
Track verified capabilities and completed workflows, not gamified streaks alone.

## Consent UX
Separate consent for file upload, account connection, write access, telemetry and provider access. Explain revocation.

## Acceptance criteria
The user can always understand the next step, cost, data exposure and human responsibility.
