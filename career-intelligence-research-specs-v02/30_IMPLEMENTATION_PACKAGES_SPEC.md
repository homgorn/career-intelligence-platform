# Implementation packages

Commercial and operational packages that convert recommendations into completed outcomes.

## Packages

Discover; Starter; Guided Setup; Workflow Pack; Team Transformation; Managed AI.

## Each package

Scope; prerequisites; deliverables; owner; duration range; price model; acceptance criteria; support; rollback; measurement.

## No-value gate

If expected benefit is too small, risk too high, or maintenance cost too high, recommend not implementing.
