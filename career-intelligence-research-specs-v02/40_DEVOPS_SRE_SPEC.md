# DevOps, SRE and release engineering

Production reliability and change management for a multi-service AI product.

## Environments

Local → CI → preview → staging → production. Production data is never copied to lower environments without approved anonymization.

## Release gates

Tests; security scan; migration safety; eval suite; policy checks; observability readiness; rollback plan.

## SRE

Error budgets; latency SLOs; dependency health; queue depth; model/provider failure rates; cost anomalies; backup restore tests.
