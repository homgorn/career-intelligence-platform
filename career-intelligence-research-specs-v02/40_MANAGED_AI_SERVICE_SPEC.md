# Managed AI & Done-for-You Service Specification

## Product intent
Serve users who want an outcome but do not want to learn tools or configure systems themselves.

## Service models
- concierge setup: one-time configuration;
- implementation partner: discovery through launch;
- managed workflow: recurring monitoring and support;
- human-assisted service: AI prepares, specialist reviews;
- referral marketplace: qualified external providers.

## Service lifecycle
Intake → scope → data/permission review → proposal → explicit approval → setup → acceptance test → handover → support → renewal/exit.

## Provider qualification
Profession competence, AI implementation experience, security practices, insurance/liability where relevant, references, response times, transparent pricing and conflict-of-interest disclosure.

## User protections
Named responsible provider, written scope, data processing terms, access expiration, audit trail, exportability, cancellation, credential revocation and deletion confirmation.

## Marketplace controls
Reviews must be tied to verified completed work; disclose sponsored placement; separate ranking from commission; handle complaints and provider suspension.

## Acceptance criteria
A done-for-you package has measurable acceptance criteria, a handover/runbook and a clear owner after the provider leaves.
