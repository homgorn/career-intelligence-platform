# Admin / Taxonomy / Content Operations Specification

## Admin controls
occupations, categories, skills, aliases, seniority, credentials, geography, market data, training, rules, quiz modules, explanation templates.

## Workflow
draft → review → evidence check → expert approval → publish → monitor → deprecate.

## Source registry
source, date, geography, type, reliability, review/expiry.

## Reproducibility
Recommendation must be reproducible against taxonomy version, market snapshot, rules version and model version.

## Conflict resolution
O*NET/ESCO/local sources can disagree; retain provenance and context rather than silently merging.

## Localization
Translations change labels, not canonical occupation IDs.
