# Agent runtime and orchestration

Controlled agent execution for tasks where multi-step tool use is justified.

## Agent types

Research agent; profile agent; workflow planner; implementation agent; support agent; evaluator; monitoring agent.

## State

Explicit run state, tool calls, approvals, retries, checkpoints, artifacts and termination reason.

## Agency levels

Suggest-only → draft → user-approved action → bounded autonomous action → monitored automation. Default to the lowest level that solves the task.

## Observability

Trace every tool call, input class, output, latency, cost, policy result and human approval.
