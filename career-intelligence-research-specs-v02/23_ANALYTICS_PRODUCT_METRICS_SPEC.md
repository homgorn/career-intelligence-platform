# Product analytics and KPI tree

Measurement architecture from acquisition through verified customer outcome.

## North-star candidates

Verified useful outcome per active customer; or outcome-adjusted active customers. Choose one after validation rather than optimizing engagement by default.

## Core metrics

Activation; time-to-first-value; recommendation acceptance; implementation completion; outcome verification; retention; paid conversion; CAC; LTV; gross margin; referral rate.

## Quality metrics

Recommendation precision; harmful recommendation rate; unsupported claim rate; tool failure rate; user override rate; human-review rate.

## Instrumentation

Every major action carries event ID, user/tenant context, experiment ID, engine version and outcome linkage.
