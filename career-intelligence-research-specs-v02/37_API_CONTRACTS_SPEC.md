# API and integration contracts

Stable API surface for web, mobile, partner and agent clients.

## API principles

Versioned; idempotent; typed errors; pagination; rate limits; authorization scopes; audit correlation IDs; backward compatibility policy.

## Core APIs

Profile; taxonomy; task/workflow; recommendations; recipes; tools; learning; outcomes; jobs; partners; billing; admin; audit; search.

## External adapters

Provider-specific fields stay outside canonical API objects.
