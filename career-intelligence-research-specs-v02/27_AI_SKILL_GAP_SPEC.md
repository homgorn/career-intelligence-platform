# AI Skill Gap Specification

## Purpose
Identify the smallest set of skills a person needs to use AI safely and productively in their actual work.

## Skill families
1. AI literacy: capabilities, limits, hallucinations, model variability.
2. Task framing: describe goal, context, constraints and desired output.
3. Context provision: provide relevant files, examples and source material safely.
4. Output verification: check facts, calculations, citations, completeness and tone.
5. Tool operation: upload, export, connect, configure and troubleshoot.
6. Workflow thinking: identify trigger, inputs, steps, handoffs and exceptions.
7. Data hygiene: classify sensitive data, redact and control access.
8. Automation literacy: triggers, actions, conditions, approvals, logs and recovery.
9. Domain expertise: recognize incorrect or unsafe advice in the profession.
10. Change and communication: explain new process and document it.

## Gap states
Unknown / absent / beginner / functional / independent / advanced / mentor.
Assess through demonstrated tasks, not self-rating alone.

## Learning recommendation
For each gap:
- why it matters in the user's work;
- one short explanation;
- guided exercise using a realistic task;
- worked example;
- verification checklist;
- next practice task;
- evidence required to mark as mastered.

## Avoid
- teaching prompt engineering as a goal in itself;
- forcing coding or API skills on non-technical users;
- assuming that tool familiarity equals safe competence;
- confusing AI knowledge with professional competence.

## Acceptance criteria
A skill is marked mastered only after a practical demonstration or explicit evidence, with recency and confidence recorded.
