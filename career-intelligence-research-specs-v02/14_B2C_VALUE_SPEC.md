# B2C customer value model

B2C value is defined as improved career/work outcomes, not time spent in the app.

## Primary jobs

Choose direction; understand fit; find next role; close skill gaps; improve current work; adopt AI safely; build portfolio; prepare applications; plan transition.

## Value equation

Expected value = probability of useful outcome × magnitude of outcome − money cost − time cost − implementation friction − risk.

## Activation

User reaches a concrete personalized recommendation and completes or validates one action that matters to their goal.

## Retention

Return is justified by evolving work, market signals, learning progress, job search, workflow outcomes or periodic reassessment—not generic daily engagement.

## Anti-pattern

Do not manufacture engagement through endless quizzes, generic AI tips or low-value notifications.
