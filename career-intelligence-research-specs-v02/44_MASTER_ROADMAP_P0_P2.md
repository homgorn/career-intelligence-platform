# Master roadmap P0/P1/P2

Execution roadmap. P0 validates the core value loop; P1 scales repeatability; P2 builds moat and ecosystem.

## P0 — prove value

1. Choose one ICP and one profession/workflow.
2. Implement profile + task diagnosis + one WorkRecipe.
3. Add evidence/provenance and policy gates.
4. Ship basic website, onboarding, analytics and billing.
5. Manually verify recommendations and outcomes.
6. Publish 10–30 high-quality profession/task pages.
7. Run acquisition experiments.
8. Measure time-to-first-value and verified outcome.

## P1 — productize

Expand taxonomy; recipe library; tool registry; learning; integrations; B2B diagnostic; partner program; CRM; SEO scale; evaluation suite; support/runbooks; marketplace pilot.

## P2 — moat

Knowledge graph; outcome intelligence; agent runtime; managed AI; enterprise governance; marketplace scale; data flywheel; internationalization; advanced personalization.

## Gate

Do not move from P0 to P1 because the feature backlog is complete. Move only when evidence shows repeatable value and acceptable unit economics.
