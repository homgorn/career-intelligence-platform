# IDE-ready task schema

Canonical task format for coding agents and project management systems.

## Task fields

task_id; title; objective; customer_value; priority; status; context; dependencies; inputs; outputs; affected_domains; required_skills; recommended_plugins; implementation_notes; tests; security; legal; analytics; acceptance_criteria; definition_of_done; rollback; evidence.

## DoD

Code/config implemented; tests pass; security/privacy checks pass; telemetry added; docs updated; migration/recovery verified; acceptance criteria demonstrated.

## Agent rule

Agents may implement within declared scope. They must not silently change domain contracts, policy, security boundaries or legal assumptions.
