# MCP, plugin and tool registry

Provider-neutral registry for tools and agent capabilities.

## Tool record

tool_id, provider, capability, input_schema, output_schema, auth_scope, risk_class, data_class, supported_regions, pricing, version, health, verification_date, owner.

## MCP

Use MCP where it materially improves interoperability. Treat every server/tool as an untrusted integration boundary with explicit scopes and policy controls.

## Installation modes

Native connector; OAuth connector; API; MCP server; browser/RPA; manual service; human expert.

## Lifecycle

Discovered → reviewed → verified → available → deprecated → retired.
