# AI Implementation Packages Specification

## Purpose
Offer a ladder of help for users with different confidence, time, budget and technical ability.

## Package ladder
### 1. Discover
Task audit, AI opportunity map, readiness, risk triage and prioritized roadmap. No production changes.

### 2. Starter
One assistant, safe settings, three profession-specific templates, first guided task and verification checklist.

### 3. Guided Setup
Connect selected tools, configure one workflow, train user, document setup and test with sample data.

### 4. Workflow Pack
Two to five connected workflows, role permissions, exception handling, logs, runbooks and measured pilot.

### 5. Business Automation
Process redesign, system integrations, multiple roles, admin controls, monitoring, support and ROI review.

### 6. Managed AI
Ongoing monitoring, updates, incident response, usage review, retraining and quarterly optimization.

## Package card
Target user, outcome, included scope, excluded scope, prerequisites, duration range, customer effort, provider effort, one-time cost range, recurring cost, support SLA, data access, deliverables, acceptance test and exit/export plan.

## Guardrails
- No hidden recurring charges.
- No claim of guaranteed savings.
- No automation before process mapping.
- No production access without least-privilege and explicit approval.
- Provide a DIY path and an exit path.
- Separate vendor software fees from implementation fees.

## Acceptance criteria
User understands exactly what will be delivered, what they must provide, what remains manual and how completion is verified.
