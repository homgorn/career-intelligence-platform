# Skills and plugin execution map

Maps project tasks to the capabilities needed to implement them.

## Skill taxonomy

Product strategy; UX; frontend; backend; data; SQL; search; LLM/RAG; agent engineering; security; legal ops; SEO; content; analytics; ads; CRM; sales; partnerships; support; DevOps.

## Task card

task_id; required_skill; optional_skill; recommended_tool/plugin; inputs; outputs; acceptance criteria; estimated complexity; dependency; reviewer.

## Rule

A plugin is an implementation aid, not a product requirement. The architecture must remain operable if a specific plugin disappears.
