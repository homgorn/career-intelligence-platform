# Evaluation and benchmark framework

Evaluation must test the system as a decision-support product, not only the language model.

## Offline evals

Profile extraction; occupation mapping; task mapping; tool selection; learning path; explanation correctness; policy classification; citation quality.

## Online evals

Activation, completion, outcome rate, user correction, escalation, cost per successful outcome.

## Benchmark sets

Golden cases by profession, seniority, language, geography, beginner/advanced AI literacy, B2C/B2B and high-risk/low-risk workflows.

## Release gate

No model/provider change reaches production if critical safety or recommendation metrics regress beyond agreed thresholds.
