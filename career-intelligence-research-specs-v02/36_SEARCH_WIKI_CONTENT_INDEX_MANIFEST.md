# Search, wiki and content index manifest

Machine-readable logical indexes that IDE and retrieval services can consume.

## Indexes

idx_occupation; idx_skill; idx_task; idx_workflow; idx_tool; idx_recipe; idx_evidence; idx_source; idx_job; idx_learning; idx_policy; idx_case; idx_content.

## Metadata

Each index specifies primary key, searchable fields, filters, freshness, ACL, ranking and rebuild source.

## Canonical rule

No duplicate canonical entity is allowed without an explicit merge/alias record.
