# Human Support & Escalation Specification

## Purpose
Give novices a path when automation, documentation or AI output fails.

## Support tiers
- self-serve guide;
- contextual help and troubleshooting;
- community / peer support;
- trained onboarding coach;
- profession expert;
- technical integration specialist;
- security / compliance escalation.

## Escalation triggers
Repeated failure, safety concern, suspected data leak, account compromise, billing dispute, incorrect consequential output, blocked integration or unclear ownership.

## Support record
Issue category, workflow/version, sanitized diagnostics, severity, owner, response target, resolution, root cause and prevention.

## Boundaries
Support staff must not request passwords, unrestricted account access or unnecessary personal/customer data. Use time-limited delegated access where possible.

## Acceptance criteria
Every production workflow has a support route, severity classification and clear instruction for disabling it safely.
