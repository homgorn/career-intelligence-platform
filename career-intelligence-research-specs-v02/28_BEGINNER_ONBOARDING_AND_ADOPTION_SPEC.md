# Beginner adoption and implementation

A user far from AI must still reach value without learning AI vocabulary first.

## Journey

Goal → describe current work → identify one painful task → safe recommendation → guided implementation → verify result → save recipe → expand.

## Three modes

Do it myself; guide me step-by-step; do it with/for me where policy permits.

## Failure recovery

Every recipe has undo/rollback, troubleshooting and escalation paths.

## Progress

Measure demonstrated capability, not course completion alone.
