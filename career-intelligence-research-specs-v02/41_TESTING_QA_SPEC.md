# Testing strategy

Quality gates across deterministic code, data, AI and user outcomes.

## Layers

Unit; integration; contract; E2E; authorization; migration; data quality; retrieval; model eval; adversarial; accessibility; performance; chaos.

## AI tests

Prompt injection; citation integrity; hallucination/unsupported claim; tool authorization; refusal behavior; regression by model version.

## Release

Critical failures block release. Medium failures require explicit risk acceptance.
