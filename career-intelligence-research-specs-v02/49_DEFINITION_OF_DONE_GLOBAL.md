# Global Definition of Done

A feature is not done because code exists. It is done when customer value, correctness, security, operations and measurement are demonstrated.

## Required

Customer-value statement; acceptance criteria; automated tests; security/privacy review; legal review trigger checked; analytics; documentation; support/runbook; rollback; cost estimate; owner; evidence.

## AI-specific

Model/provider/version recorded; evals pass; provenance/citations validated; tool permissions constrained; failure behavior tested.

## Production

Monitoring; alert; backup/recovery impact; migration plan; deployment/rollback tested.
