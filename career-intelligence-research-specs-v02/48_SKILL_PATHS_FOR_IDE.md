# Skill paths for implementation

Suggested skill decomposition for an IDE/agent workflow.

## Foundation

Product discovery → domain modeling → API design → PostgreSQL → authorization → testing → observability → deployment.

## AI

LLM structured outputs → RAG → evaluation → tool calling → MCP → agent orchestration → human review.

## Growth

Technical SEO → programmatic SEO → analytics → CRO → content systems → paid acquisition → CRM.

## Enterprise

Multi-tenancy → RBAC/ABAC → privacy → security → audit → billing → procurement readiness.

## Rule

Skills are selected per task card. Do not install every tool/plugin upfront.
