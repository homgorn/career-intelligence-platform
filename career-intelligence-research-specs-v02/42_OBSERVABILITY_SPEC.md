# Observability

Unified traces and metrics across product, LLM, tools and business outcomes.

## Trace

request → engine → retrieval → model → tool → policy → output → user action → outcome.

## Metrics

Latency; token/cost; tool error; policy blocks; retrieval hit rate; model quality; conversion; outcome.

## Privacy

Logs use redaction and data-classification rules. Sensitive payloads are not logged by default.
