# Occupation & Career Taxonomy Specification

## Hierarchy
Domain → Sector → Career Family → Occupation → Specialization → Sub-specialization → Role → Variant.

Example:
Construction → Electrical → Electrician → Industrial Electrician → Automation Electrician → PLC/Industrial Controls Technician.

## Canonical occupation
Must contain:
- canonical title;
- alternate titles;
- tasks;
- skills;
- knowledge;
- tools;
- credentials;
- work context;
- industries;
- seniority;
- adjacent occupations.

## Specialization
- parent occupation;
- differentiating skills;
- tools;
- employers;
- market signal;
- training;
- licensing;
- risks;
- adjacent paths.

## Crosswalk
O*NET / ESCO / local classification / internal ID / multilingual titles.

## Governance
version + source + reason + effective date + deprecated flag.

## Anti-chaos
New title ≠ new occupation. Create new occupation only when core tasks/skills/context/qualification/market behavior materially differ.
