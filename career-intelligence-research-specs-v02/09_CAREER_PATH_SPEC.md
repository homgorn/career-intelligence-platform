# Career Path & Transition Specification

## Path types
entry, lateral, promotion, specialization, industry transfer, geography transfer, remote transition, freelance, entrepreneurship.

## Path
current state → target occupation → intermediate roles → skills → credential → proof → application → job.

## Transition record
required skills, transferable skills, missing skills, training, effort, cost, opportunity cost, credential, evidence, market, blockers.

## Adjacent move engine
Prefer transitions with high transferable-skill overlap.

## Compare paths
fastest / cheapest / highest income / lowest risk / best lifestyle / strongest long-term.

## Time
Use ranges, not promises.

## Proof-first
Course completion is not equivalent to experience. Prefer projects, supervised work, certification or practical proof.

## Recompute
Completed course/project/certification/job triggers profile and path recalculation.
